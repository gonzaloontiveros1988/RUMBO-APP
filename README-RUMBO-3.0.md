# RUMBO 3.0 — Definitive model preview

This branch contains the product definition and an interactive HTML concept for the next generation of RUMBO.

## Open the concept
- `rumbo-definitive-model.html`: complete multi-module interactive concept.
- `docs/RUMBO-DEFINITIVE-PRODUCT-MODEL.md`: definitive product specification.
- `docs/RUMBO-3.0-MASTER.md`: architecture and phased delivery plan.
- `docs/RUMBO-3.0-TECHNICAL-AUDIT.md`: static audit of the legacy application.
- `docs/RUMBO-AI-SPEC.md`: AI agents, autonomy and safety.

## Preview notes
The HTML file is a standalone concept. It has responsive layouts, navigation and local demo interactions. It does not connect to Firebase, the legacy state, personal roster, health sources or family records. All displayed routes, hours, dates and household metrics are sample data.

## Branch policy
Development branch: `redesign/rumbo-os-v4`. Do not merge to `main` or replace the production app until data migration, security, backup restoration and device testing have passed and the owner accepts the release.
